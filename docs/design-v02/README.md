# Visual Corp · diseño v02

Esta carpeta contiene una lámina interactiva para revisar la primera dirección visual compartida en web, admin y POS.

## Abrir

Abre `index.html` en un navegador. Los controles superiores cambian entre las tres áreas, tema claro/oscuro y composición de escritorio/móvil.

## Alcance

- Es un prototipo visual independiente. No modifica rutas, componentes, estilos, datos ni comportamiento del producto.
- La carpeta `assets/` contiene copias del wordmark, símbolo y fuente Bebas Kai de `public/`, tres pesos de DM Sans de `VISUAL REFRESH/POSIBLES FUENTES/DM SANS` y Visualito del paquete de referencias de marca. Se conservan todos los originales.
- El texto de portada y los tres servicios se tomaron del contenido de la aplicación existente.
- Nombres, contactos, métricas, solicitudes, productos, existencias, códigos y precios del admin/POS son datos ficticios de muestra. No son registros ni tarifas comerciales.
- Los colores y medidas son propuestas de interfaz del Plan v02; requieren revisión visual y de contraste antes de implementarse como sistema definitivo.
