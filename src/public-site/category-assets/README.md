# Ilustraciones del catálogo de inicio

`category-atlas-brand-v01.png` es una hoja 2×2 generada para las cuatro familias enlazadas desde la página principal. Mantiene escenarios de producto en tonos neutros y usa acentos discretos derivados del degradado de Visual Corp. No contiene marcas, textos, Visualito ni fotografías de clientes o trabajos instalados.

La hoja se exporta como `public/public-site/categories/category-atlas.webp` para la interfaz. Las cuatro tarjetas recortan cada cuadrante como imagen ilustrativa; los nombres y descripciones permanecen en HTML accesible. No presentar estas imágenes como portafolio ni como evidencia de trabajos ejecutados.

Fuente de identidad cromática: `00_Guia_y_contexto/GUIA_IDENTIDAD_VISUAL_DIGITAL_v02.md`, que registra negro/blanco como bases y el degradado observado en el maestro de marca (cian/azul, violeta, magenta, naranja y amarillo). Los HEX usados en la generación son aproximaciones de pantalla y no especificaciones de producción.
